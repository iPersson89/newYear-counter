# newYear-counter
js-beginer programming
Övning 1: Nedräknare till Nyår
•	W3School-kategorier: JS Output, JS Syntax, JS Strings, JS Dates, JS Math
•	Uppgift: Skapa ett script som tar dagens datum, beräknar hur många dagar det är kvar till den 31 december, och skriver ut ett personligt meddelande i terminalen med användarens namn i versaler.
•	Funktioner & Begrepp att använda:
o	console.log()
o	new Date() och tidsstämplar i millisekunder
o	Math.floor() för att avrunda millisekunder till dagar
o	String-metod: .toUpperCase()
o	Template literals (sök på JS String Templates) för utskriften
